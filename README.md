# Site Marcenaria Butantã

Site institucional multipágina da **Marcenaria Butantã**, marcenaria de móveis planejados em São Paulo. Em produção em [marcenariabutanta.com.br](https://marcenariabutanta.com.br).

## Páginas

| Página | Conteúdo |
|---|---|
| index.html | Apresentação da marcenaria e serviços |
| cozinhas-planejadas.html | Portfólio de cozinhas |
| dormitorios-planejados.html | Portfólio de dormitórios |
| home-office-planejado.html | Portfólio de home office |
| orcamento.html | Pedido de orçamento com contato direto pelo WhatsApp |

## Estrutura

- style.css: estilos e layout responsivo
- script.js: interações da página
- assets/ e Fotos/: imagens dos projetos
